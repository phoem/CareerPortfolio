# LM Studio — Software Engineer, Applications

This package targets LM Studio's in-person New York City Software Engineer, Applications role.

## Base-resume selection

The canonical Senior Software Engineer resume was selected as the closest base because it best combines application development, systems engineering, integrations, security, and cross-stack delivery. The Software Architect resume supplies relevant architecture framing but is less product-focused; the Backend / Infrastructure resume overweights production infrastructure relative to desktop product engineering.

## Package contents

- `APPLICATION.json` — machine-readable application manifest.
- `JOB_DESCRIPTION.md` — captured job-specific posting content used for tailoring and ATS validation.
- `JOB_SOURCE.md` — source URL and retrieval provenance.
- `EVIDENCE_MAP.md` — requirement-to-evidence mapping and preserved qualification boundaries.
- resume Markdown source plus generated DOCX/PDF artifacts.
- `DESIGN.json` — persistent `readable-ats` design selection.
- `validation/` — current ATS report, result data, and score history after CI validation.
